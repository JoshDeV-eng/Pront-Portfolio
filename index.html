C shader · glsl

Fluid Canvas

A browser-based fluid simulation used as an interactive hero for a music label.

△ 60fps, mobile
problem
The label wanted a launch-page hero that felt alive, but every WebGL demo the team tried tanked frame rate on mobile.
approach
Wrote a custom GLSL fluid-advection shader tuned for a shared low-res sim buffer, upsampled on the GPU to keep draw calls minimal.
result
Held a steady 60fps on mid-range mobile; the page became the label's most-shared launch asset that quarter.

Design Sync

A Figma plugin that pushes live component tokens straight into a production design system.

△ zero drift
problem

approach
Built a Figma plugin on the Figma API that reads variable collections and opens a PR against the design-token repo automatically.
result
Token drift dropped to zero across three product teams; design QA time cut by roughly half.
